Open Data

ARGOS is built entirely on open data. These are the datasets that power the digital twin.

OpenStreetMap

OpenStreetMap Contributors · ODbL
What it contains

12,217 roads, 22,013 original building footprints, 1,831 POIs, beach geometries

How ARGOS uses it

Base map, routing network, original building layer, POI and beach locations

Copernicus Sentinel-2

ESA / Copernicus · Free and open
What it contains

10m multispectral imagery, red edge, SWIR

How ARGOS uses it

NDVI, vegetation stress, burn scar detection, fuel type proxy

Copernicus DEM

ESA / Copernicus · Free and open
What it contains

30m digital elevation model

How ARGOS uses it

Slope, aspect, drainage direction, terrain analysis

EFFIS

JRC / Copernicus · Free and open
What it contains

Historical fire records, burnt area shapefiles, fuel maps

How ARGOS uses it

Model validation, fuel type comparison, burn scar overlay

EMODnet

EU / EMODnet · Free and open
What it contains

Bathymetry, seabed habitats, human activities

How ARGOS uses it

Marine safety layers, subsurface current risk at beaches

Microsoft Building Footprints

Microsoft · CDLA Permissive 2.0
What it contains

Machine-detected building polygons from satellite imagery, with confidence scores and height estimates where available

How ARGOS uses it

Adds 24,921 footprints with no OpenStreetMap partner, lifting the merged building layer from 22,013 to 46,934 after PostGIS conflation

Note on methodology

Every dataset is preserved in its original form before transformation. Raw data lives in data/raw/. Processed data lives in data/processed/. The pipeline is documented in the ARGOS Code Bible. No black boxes.
